# Prashorst (Eric) Meas — Portfolio

Personal portfolio website showcasing the bioinformatics research, computational simulations, and AI software engineering of **Prashorst (Eric) Meas** (Melbourne, Australia).

## Run locally

Zero external dependencies required — run with Node.js (18+) or Python 3:

```bash
npm start
# Opens on http://127.0.0.1:4175
```

Or with Python:

```bash
python3 -m http.server 4175
```

## Deploy to GitHub Pages

This is a static site (`index.html`, `styles.css`, `app.js`, `data.js`, and `assets/`). Push this directory to `prashorstmeas.github.io` (or enable GitHub Pages on any repository branch) with no build step required.
